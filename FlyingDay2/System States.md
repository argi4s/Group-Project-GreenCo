System States

System States (FSM) as of FLIGHTDAY2 DRAFT

```
INIT: Initial state, waiting for GUIDED mode

TAKEOFF: Taking off to specified altitude

FLIGHT: Hovering or awaiting commands

LAWNMOWER: Executing lawnmower search pattern

AOI: Area of Interest inspection mission

RETURN: Returning via pre-defined waypoints

LAND: Landing sequence

RTL: Return to Launch (emergency/command)

EMERGENCY: Immediate disarm
```
